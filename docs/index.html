겪어본 상황처럼, 자연스럽게 말하기

IGP의 목표는 환자와 마주한 상황에 익숙해져, 필요한 말이 자연스럽게 나오는 것입니다. 같은 대화를 여러 번 듣고 직접 말하며, 낯선 상황을 익숙한 경험으로 만들어 보세요.

  1. 상황을 그려보세요. 오늘의 환자는 누구이고, 어떤 마음일까요? 내가 담당 피지오라면 어떻게 말할지 떠올려 보세요.
  2. Eng로 듣고, 쉐도잉하세요. 문장별로 반복해서 듣고, 소리 내어 따라 하세요. 단어뿐 아니라 말의 리듬과 환자를 대하는 따뜻한 톤까지 익혀 보세요.
  3. Kor로 떠올리고, Blind로 말해보세요. 한국어만 보고 영어 대사를 말한 뒤, 익숙해지면 대본을 가려보세요. 막히면 말풍선을 눌러 확인하고 다시 도전하세요.
  4. 짧게, 자주 반복하세요. ‘반복’과 ‘따라 말할 틈’을 활용해, 머릿속으로 아는 표현이 입에서 바로 나올 때까지 연습해 보세요.

주 1회 스피킹 세션에서 함께 말해요

혼자 익힌 표현을 사람과 주고받으며 내 말로 만드는 시간입니다. 완벽하게 준비되지 않았어도 괜찮아요. 매주 스피킹 세션에 꼭 참여해 주세요. 서로 환자와 피지오가 되어, 반복한 대화를 실제 대화로 이어가 봅시다.

학습 자료를 불러오고 있어요.
